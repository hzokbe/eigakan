# Eigakan

Eigakan é uma aplicação web que permite que usuários explorem um catálogo de animes e mangás, montem suas listas
pessoais, avaliem títulos e marquem favoritos.

## Documentação

O projeto é documentado em arquivos separados, cada um cobrindo uma etapa do desenvolvimento:

| Arquivo                                       | Conteúdo                               |
|-----------------------------------------------|----------------------------------------|
| [`REQUIREMENTS.md`](./docs/REQUIREMENTS.md)   | Requisitos funcionais e não funcionais |
| [`DATA_MODELING.md`](./docs/DATA_MODELING.md) | Modelagem de dados                     |
| [`ARCHITECTURE.md`](./docs/ARCHITECTURE.md)   | Índice das decisões de arquitetura     |
| [`MODELS.md`](./docs/MODELS.md)               | Modelos e suas colunas/relacionamentos |
| [`ROUTES.md`](./docs/ROUTES.md)               | Mapeamento de rotas                    |
| [`CONTROLLERS.md`](./docs/CONTROLLERS.md)     | Controllers e suas responsabilidades   |
